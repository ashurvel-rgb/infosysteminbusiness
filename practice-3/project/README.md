# Практическая работа №3-4

Типы данных, арифметика и корректный расчёт показателей

Выполнил: Велиханов Ашурбег, ЭФБО-17-25.

Проект рассчитывает базовую стоимость заказа, применяет скидку, начисляет НДС на сумму после скидки и выводит итог с двумя знаками после запятой. Реализован индивидуальный вариант 2: максимальная скидка составляет 15 %.

## Проверка 14.10.2026

SelfCheck: 28 успешных проверок. Дополнительно выполнены 10 проверок консольного ввода. Подробности — в TEST_RESULTS.md. Пустая строка, EOF, неверный формат, NaN и Infinity обрабатываются без вывода результата расчёта.

При вводе указывайте четыре отдельные строки: количество, цену, скидку и НДС. Дробная часть допускает точку или запятую. sample.csv сохранён как набор примеров из трёх полей; приложение не импортирует CSV автоматически, ставку НДС следует задавать отдельно.

## Сборка без Maven

```bash
mkdir -p out
javac -encoding UTF-8 -d out $(find src -name "*.java")
java -cp out ru.edu.pr01.SelfCheck
```

В Windows можно запустить `run_selfcheck.bat`. Для ручного запуска приложения:

```bash
java -cp out ru.edu.pr01.OrderCalculator
```

## Правила проверки

- количество: от 1 до 10 000 включительно;
- цена: больше 0 и не более 5 000 000 рублей;
- скидка: от 0 до 15 % включительно;
- НДС: от 0 до 100 % включительно;
- при ошибке расчёт не выполняется, пользователь получает понятное сообщение.

Для учебной работы применяется `double`. Для промышленной финансовой системы следует использовать `BigDecimal`, чтобы управлять десятичным округлением явно.
