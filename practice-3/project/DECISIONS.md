# Принятые решения

## Вариант 2 и единая граница скидки

Максимальная скидка 15 % хранится в константе `MAX_DISCOUNT_PERCENT`. Проверка ввода и расчёт используют одну константу, поэтому изменение правила не требует правок в нескольких местах.

## Последовательность расчёта

Сначала вычисляется базовая сумма, затем применяется скидка, после этого на уменьшенную сумму начисляется НДС. Метод `calculateTotal` не дублирует формулы, а вызывает `calculateBase`, `applyDiscount` и `calculateVat`. Это связывает реализацию с Activity-диаграммой и уменьшает риск расхождения вычислений.

`double` выбран по условию учебной работы и удобен для демонстрации арифметики. В реальной системе денежные значения следует хранить и считать через `BigDecimal` с заданным режимом округления.
