## Практическая работа 3–4

Отчёт находится в `practice-3/report.docx`, исходный Java-проект — в `practice-3/project`.

Вариант 2: максимальная скидка 15%. Количество — 1–10000, цена — больше 0 и не более 5000000 рублей. НДС вводится в процентах и начисляется после скидки. Пустой ввод, EOF, неверный формат, NaN, Infinity и недопустимые диапазоны приводят к сообщению об ошибке без расчёта.

Для сборки нужен JDK 8 или новее. В каталоге `practice-3/project`:

```sh
javac -encoding UTF-8 -d out src/ru/edu/pr01/*.java
java -cp out ru.edu.pr01.SelfCheck
java -cp out ru.edu.pr01.OrderCalculator
```

Вводятся четыре строки: количество, цена за единицу, скидка в процентах, ставка НДС в процентах. Пример: `2`, `100`, `10`, `20`; результат — `216,00 руб.`.

Проверка 14.10.2026: 28 успешных тестов SelfCheck и 10 успешных проверок консоли. Журнал — `practice-3/project/TEST_RESULTS.md`, решения — `DECISIONS.md`, диаграммы — `diagrams`.
